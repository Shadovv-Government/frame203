# Проверки приложения

Проверено 17.11.2026 в среде сборки, Chromium 134 / Python 3.12. Это проверка приложения, не вашей реальной согласованности.

- Синтаксис JavaScript и Python.
- Чтение реальных форматов из публичной ветки annotation (agreement.py/build_gold.py).
- CSV round-trip на 60 SMS и 157 строках рамок, полученных в изолированном тесте A против A. Это **не** сравнение Кирилла с Григорием: экспорт B в доступной среде отсутствует.
- Кавычки, запятые, переносы строк и BOM в CSV; обнаружение повреждённого CSV.
- Браузерный сценарий SMS: принять A → комментарий → сохранить → запись CSV.
- Браузерный сценарий машин: принять B → сохранить → use=B.
- Создание резервных копий; запрет записи после внешнего изменения файла.
- Совместимость сохранённых таблиц с неизменённым build_gold.py: оба вида gold успешно собраны на тестовых копиях.
- Просмотр рядом/наложение, масштабирование, мобильный экран 375px без горизонтального переполнения, светлая/тёмная темы.
- Односторонние рамки only_A/only_B и их удаление на искусственной тестовой конфигурации интерфейса.
- Папка в режиме чтения, скачивание корректного CSV.
- Отсутствующее изображение не позволяет подтвердить рамку.
- Контрольные суммы исходных JSON остались прежними.

Прямая запись тестировалась в браузере через адаптер файловых дескрипторов, записывающий в изолированную временную папку. Реальный диалог прав Windows/Chrome не автоматизировался. После установки подтвердите первую запись и проверьте CSV и backups на своём компьютере.

Локальная Windows-папка пользователя не изменялась: приложение предоставлено архивом для распаковки в репозиторий.
